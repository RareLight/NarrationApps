# Native longform evaluation fixtures

`corpus.json` is original synthetic text generated for this project and distributed
under the repository license. It contains no private book/article data or copied
third-party prose. Keep its spoken blocks stable when comparing archived runs.

`frontend.json` contains focused expected phonemes from the pinned US/GB Misaki
lexicons and the audited number/currency path. Regional stress/vowel differences
are intentional. The indivisible lowercase overlong word must fail before synthesis;
it exercises the existing BART positional limit without truncation. Native checks
also exercise an invented in-range out-of-dictionary name. Matching these expected
values verifies regression conformance, not voice quality or all English grammar.

Currency/decimal expectations accompany independent Foundation English-word
fixtures in `DependencyTests/EnglishNumbers.swift`. The audit found that the old
native frontend could omit short decimal strings as empty acronyms and lose
currency context when Apple tagged amounts as OtherWord. Those omissions are
expected differences from the archived baseline, not source edits in this corpus.

The homograph and unit-abbreviation passages remain deliberate listening cases.
Do not install an ASR model merely to manufacture a quality score, or silently
edit the passage to avoid an uncertain pronunciation. Native PDF/Markdown workload
fixtures are generated by MixedDocumentCheck; original private files stay with
the operator.

Synthetic contents-page rows exercise repeated dotted leaders, accented headings
and long windows. They must retain complete, non-overlapping source coverage in
the actual prepared frontend. These regressions reproduce the October 15 ebook
failure without including the operator-supplied PDF or its prose.

The overlong fixture uses an indivisible lowercase word. Mixed-case input may
legitimately split at camel-case boundaries; its previous rejection could come
from the overlapping-range bug rather than the BART input ceiling. The lowercase
fixture isolates the intended positional-table rejection without truncation.
