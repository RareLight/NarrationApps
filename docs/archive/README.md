# Documentation archive

Dated implementation records, review records and research that are no longer
current guidance. They are kept for provenance: they explain why decisions were
made and record the evidence gathered at the time.

Do not follow these documents as setup instructions, checklists or authorization
for new work. Their stage commands, test counts, commit IDs and build paths are
historical. For current guidance use the [documentation index](../README.md);
the [documentation policy](../DOCUMENTATION.md) defines when a document moves here.
